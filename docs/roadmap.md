# Roadmap de University Hub

## Fase 1 — Prototipo web publicado
- [x] Identidad visual y navegación responsive inicial.
- [x] Panel general.
- [x] Alta de materias.
- [x] Tareas y seguimiento.
- [x] Calendario mensual.
- [x] Calificaciones y promedio básico.
- [x] Perfil y trayectoria editable.
- [x] Tema claro/oscuro.
- [x] Persistencia local en navegador.
- [x] Página de entrada en la raíz para GitHub Pages.

## Fase 2 — Completar experiencia académica
- [ ] Horario semanal editable.
- [ ] Exámenes y eventos con recordatorios.
- [ ] Evaluaciones ponderadas y simulador de calificación necesaria.
- [ ] Notas y recursos por materia.
- [ ] Planificador de estudio y objetivos semanales.
- [ ] Estadísticas y gráficas accesibles.
- [ ] Exportación CSV/Excel y respaldo/restauración de datos.
- [ ] Búsqueda, filtros y estados vacíos en todos los módulos.

## Fase 3 — Backend multiusuario
- [ ] Proyecto Django y API REST versionada.
- [ ] PostgreSQL y migraciones.
- [ ] Registro, inicio de sesión y recuperación de cuenta.
- [ ] Permisos por usuario y pruebas de seguridad.
- [ ] Sincronización entre dispositivos.
- [ ] Exportación y eliminación de cuenta.

## Fase 4 — Catálogo académico
- [ ] Catálogo de instituciones, campus, facultades y carreras.
- [ ] Planes de estudio versionados con fuente y fecha de verificación.
- [ ] Mapa curricular y seriación.
- [ ] Cálculo de avance por materias y créditos.
- [ ] Historial al cambiar de carrera o plan.

## Fase 5 — Calidad y producción
- [ ] Pruebas unitarias, integración y accesibilidad.
- [ ] Monitoreo, copias de seguridad y documentación operativa.
- [ ] Despliegue del backend y base de datos.
- [ ] Política de privacidad y términos de uso.
