# Roadmap de University Hub

## Fase 1 — Prototipo web publicado
- [x] Identidad visual y navegación responsive inicial.
- [x] Panel general.
- [x] Explorador inicial de Actuaría, Ciencias de la Computación e Ingeniería en Computación.
- [x] Fichas con áreas, materias frecuentes, habilidades y herramientas orientativas.
- [x] Selector de carrera en el perfil.
- [x] Alta de materias.
- [x] Tareas y seguimiento.
- [x] Calendario mensual.
- [x] Calificaciones y promedio básico.
- [x] Perfil y trayectoria editable.
- [x] Tema claro/oscuro.
- [x] Persistencia local en navegador.
- [x] Página de entrada en la raíz para GitHub Pages.

## Fase 2 — Completar experiencia académica
- [ ] Horario semanal editable.
- [ ] Exámenes y eventos con recordatorios.
- [ ] Evaluaciones ponderadas y simulador de calificación necesaria.
- [ ] Notas y recursos por materia.
- [ ] Planificador de estudio y objetivos semanales.
- [ ] Estadísticas y gráficas accesibles.
- [ ] Exportación CSV/Excel y respaldo/restauración de datos.
- [ ] Búsqueda, filtros y estados vacíos en todos los módulos.
- [ ] Herramientas especializadas: calculadora actuarial/financiera, laboratorio de algoritmos y organizador de prácticas de hardware/redes.

## Fase 3 — Backend multiusuario
- [ ] Proyecto Django y API REST versionada.
- [ ] PostgreSQL y migraciones.
- [ ] Registro, inicio de sesión y recuperación de cuenta.
- [ ] Permisos por usuario y pruebas de seguridad.
- [ ] Sincronización entre dispositivos.
- [ ] Exportación y eliminación de cuenta.

## Fase 4 — Catálogo académico oficial
- [x] Perfil académico orientado a la UNAM y enlaces a documentos oficiales identificados para seis carreras.
- [x] Diferenciar planes oficiales identificados de carreras afines sin equivalencia confirmada.
- [ ] Catálogo completo de instituciones, campus, facultades y carreras.
- [x] Mapas curriculares por semestre para cinco licenciaturas y una ruta de Ciencia de Datos, con enlaces oficiales y créditos disponibles.
- [x] Seguimiento local de asignaturas acreditadas y cálculo de avance por créditos de las materias listadas.
- [ ] Completar prerrequisitos y seriaciones materia por materia; ampliar rutas de origen de Ciencia de Datos.
- [x] Primeros planes específicos UNAM para Actuaría, Ciencias de la Computación e Ingeniería en Computación.
- [ ] Completar seriación y prerrequisitos oficiales por asignatura.
- [x] Cálculo de avance local por créditos de las materias listadas.
- [ ] Historial al cambiar de carrera o plan.

## Fase 5 — Calidad y producción
- [ ] Pruebas unitarias, integración y accesibilidad.
- [ ] Monitoreo, copias de seguridad y documentación operativa.
- [ ] Despliegue del backend y base de datos.
