# University Hub

MVP 0.1 de una plataforma de gestión académica para estudiantes de cualquier carrera.

## Ejecutar
Abre `frontend/index.html` en un navegador moderno. No requiere instalación.
Los datos de demostración se guardan en `localStorage` del navegador.

## Arquitectura prevista
- Frontend: HTML, CSS y JavaScript (prototipo actual).
- Backend: Python, Django y Django REST Framework.
- Base de datos: PostgreSQL.
- Gráficas: Chart.js (fase posterior).
- Despliegue: frontend y API por separado.

## Módulos
Panel, materias, tareas, calendario, calificaciones, trayectoria y perfil académico.

## Importante
Esta primera versión es un prototipo local. No incluye cuentas reales, sincronización ni backend conectado. Los datos iniciales son ficticios y editables.
